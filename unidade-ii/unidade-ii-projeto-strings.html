Contexto

Na primeira aula do semestre, a lousa mostrou um cadastro de alunos guardando nomes como "texto solto" num vetor de tamanho fixo — e ficou no ar a pergunta: "como guardo e manipulo texto de verdade (nomes, frases)?". Chegou a hora de responder.

Este projeto retoma o mesmo protagonista — o cadastro de alunos — e pede que cada trio implemente a parte do sistema responsável por armazenar e manipular nomes como strings de verdade: com tamanho fixo, caractere nulo, busca, correção e as funções de string.h.

A avaliação considera tanto o projeto (aula 1) quanto o código final (aulas 2-4). Não é permitido abrir o editor de código antes da aula 2.

Objetivos de aprendizagem

  • Declaração e inicialização de strings como vetores de char de tamanho fixo.
  • Processamento de strings: percorrer manualmente com laço e índice, localizar um caractere ou trecho, alterar o conteúdo de uma posição ou string inteira.
  • Funções de string.h: no mínimo strcpy e uma função de busca (strstr ou strchr). strlen e strcat aparecem nos desafios extras.

O sistema

O sistema mantém uma lista de até MAX_ALUNOS alunos usando vetores paralelos — ainda não vimos struct (isso é Unidade V), então nome e RA vivem em vetores separados, todos indexados pela mesma posição.

#define MAX_ALUNOS 20
#define TAM_NOME   50

char nomes[MAX_ALUNOS][TAM_NOME];
int  ras[MAX_ALUNOS];
int  totalAlunos = 0;

O programa deve exibir um menu em loop, repetindo até o usuário escolher sair:

===== Cadastro de Alunos =====
1. Cadastrar aluno
2. Listar todos os alunos
3. Buscar aluno por nome (busca parcial)
4. Corrigir o nome de um aluno
5. Contar ocorrências de uma letra no nome de um aluno
6. Sair
Escolha uma opção:

O que cada opção deve fazer

#AçãoConceito exercitado
1Cadastrar aluno: ler nome (aceitando nome composto, com espaço) e RA, guardar nas próximas posições livresdeclaração/inicialização, leitura com %[^\n]
2Listar todos os alunos cadastrados, um por linha, com nome e RApercorrer o vetor
3Buscar aluno digitando um pedaço do nome (ex.: "and" encontra "André" e "Andressa")localizar — strstr
4Corrigir o nome de um aluno já cadastradoalterar — strcpy
5Perguntar uma letra e um aluno, contar quantas vezes essa letra aparece no nomepercurso manual, sem strchr/strstr
6Encerrar o programa—
Por que a opção 5 existe

Ela força o percurso manual, caractere a caractere, com for e índice — sem atalho pronto da biblioteca. É o exercício que mostra que o trio entende o que string.h faz por baixo dos panos.

O que saiu daqui

Gerar etiqueta (strcat) e mostrar o nome mais longo (strlen) viraram desafios extras — quem terminar as 5 opções principais antes do fim da aula 4 parte para elas.

Esqueleto de código fornecido

Ainda não vimos como criar funções próprias (isso é conteúdo de unidade futura) — por isso todo o código de cada opção vai direto dentro do case correspondente, no main, e não em funções separadas. Para não gastar tempo de laboratório escrevendo o loop do menu, o trio recebe esta base pronta (com a opção 6 — Sair — já implementada) e preenche cada case com o código indicado pelo comentário:

#include <stdio.h>
#include <string.h>

#define MAX_ALUNOS 20
#define TAM_NOME   50

char nomes[MAX_ALUNOS][TAM_NOME];
int  ras[MAX_ALUNOS];
int  totalAlunos = 0;

int main() {
    int opcao;

    do {
        printf("\n===== Cadastro de Alunos =====\n");
        printf("1. Cadastrar aluno\n");
        printf("2. Listar todos os alunos\n");
        printf("3. Buscar aluno por nome (busca parcial)\n");
        printf("4. Corrigir o nome de um aluno\n");
        printf("5. Contar ocorrencias de uma letra no nome de um aluno\n");
        printf("6. Sair\n");
        printf("Escolha uma opcao: ");
        scanf("%d", &opcao);
        getchar(); // limpa o '\n' deixado pelo scanf("%d", ...) antes da proxima leitura de string

        switch (opcao) {
            case 1:
                // TODO opção 1 - Cadastrar aluno:
                // 1. Verificar se ainda há espaço (totalAlunos < MAX_ALUNOS).
                // 2. Ler o nome com scanf(" %[^\n]", nomes[totalAlunos]) — aceita nome composto.
                // 3. Ler o RA com scanf("%d", &ras[totalAlunos]) (lembrar do getchar() depois).
                // 4. Incrementar totalAlunos.
                break;

            case 2:
                // TODO opção 2 - Listar todos os alunos:
                // Percorrer nomes[] e ras[] de 0 até totalAlunos - 1 com um for,
                // imprimindo índice, nome e RA de cada aluno.
                break;

            case 3:
                // TODO opção 3 - Buscar aluno por nome (busca parcial):
                // 1. Ler um trecho de nome digitado pelo usuário (%[^\n]).
                // 2. Percorrer nomes[] com um for e usar strstr(nomes[i], trecho)
                //    para ver se o trecho aparece dentro do nome.
                // 3. Imprimir todos os alunos cujo nome contém o trecho.
                // 4. Se nenhum for encontrado, avisar "Nenhum aluno encontrado".
                break;

            case 4:
                // TODO opção 4 - Corrigir o nome de um aluno:
                // 1. Perguntar o índice (ou RA) do aluno a corrigir.
                // 2. Ler o novo nome (%[^\n]).
                // 3. Usar strcpy(nomes[i], novoNome) para substituir o nome antigo.
                break;

            case 5:
                // TODO opção 5 - Contar ocorrências de uma letra no nome de um aluno:
                // 1. Perguntar o índice (ou RA) do aluno e a letra a procurar.
                // 2. Percorrer nomes[i] caractere a caractere com um for e um índice
                //    (NÃO usar strchr/strstr aqui — o objetivo é o percurso manual).
                // 3. Contar quantas vezes a letra aparece e imprimir o resultado.
                break;

            case 6:
                printf("Encerrando...\n");
                break;

            default:
                printf("Opcao invalida!\n");
        }
    } while (opcao != 6);

    return 0;
}

O getchar() depois do scanf("%d", ...) existe porque o \n deixado no buffer atrapalharia a próxima leitura de nome com %[^\n] logo em seguida.

Requisitos técnicos obrigatórios

  • MAX_ALUNOS e TAM_NOME definidos como constantes (#define), não "números mágicos" espalhados pelo código
  • Nome armazenado em vetor de char de tamanho fixo — sem alocação dinâmica (ainda não vimos ponteiros)
  • Leitura de nome aceita nomes compostos (mais de uma palavra)
  • O case da opção 5 percorre a string manualmente com laço (sem usar strchr/strstr)
  • Uso de no mínimo 2 funções distintas de string.h (strcpy e strstr/strchr)
  • Busca trata o caso "nenhum aluno encontrado"
  • Programa não trava nem estoura vetor com uma entrada razoável
  • Menu roda em loop até a opção "Sair"

Desafios extras e erros comuns

Desafios extras (opcional, para quem terminar antes)

  • Gerar uma "etiqueta" concatenando nome + turma num novo vetor (ex.: "Ana Souza - Turma A"), usando strcat — atenção ao espaço, ele não é automático. (Obs.: será preciso um vetor extra para turma, não incluído no esqueleto — pensem em como adaptar a estrutura de dados.)
  • Percorrer todos os alunos e mostrar quem tem o nome com mais caracteres, usando strlen
  • Ordenar a listagem por ordem alfabética do nome, usando strcmp dentro de um algoritmo de ordenação simples (bolha)
  • Impedir o cadastro de dois alunos com nomes idênticos
  • Na busca (opção 3), ignorar diferença entre maiúsculas e minúsculas

Erros comuns — de olho nisso

scanf("%s", nome) corta o nome no primeiro espaço. Nomes compostos como "Ana Paula" ficam só "Ana". Use scanf(" %[^\n]", nome) — repare no espaço antes do %, ele descarta o \n deixado pela leitura anterior.

if (nome1 == nome2) não compara o conteúdo das strings, compara endereços de memória. Para comparar conteúdo, use strcmp(nome1, nome2) == 0.

strcat não insere espaço sozinho — a mesma pegadinha do guia de estudo da Unidade II. Se quiser um espaço na etiqueta, adicione-o manualmente antes de concatenar.

Vetor pequeno demais para o nome copiado estoura memória vizinha. Se TAM_NOME for 50 e alguém tentar strcpy de uma string maior, o programa tem comportamento indefinido. Pensem em como evitar isso ao ler o nome.
