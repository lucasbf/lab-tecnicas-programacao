Tipos nativos e o problema da string

Até o momento vimos alguns tipos de variáveis nativos da linguagem C. Os principais são:

int

Conjunto de bytes interpretado como número inteiro.

23, 56, 87643, -23948

float

Conjunto de bytes interpretado como número real (ponto flutuante).

23.5, 987.32, -2654.6

char

Um único byte interpretado como caractere — na prática, um inteiro de 0 a 255.

'a', 'Z', '7', '$'

O nome float vem justamente da capacidade desse tipo de "flutuar" a posição do ponto decimal dentro da sua representação em bits — é assim que ele consegue expressar tanto números muito pequenos quanto muito grandes com a mesma quantidade de bytes.

Já o char é, no fundo, um inteiro de 1 byte (0 a 255). O valor numérico armazenado é mapeado na tabela ASCII — sigla para American Standard Code for Information Interchange (Código Padrão Americano para o Intercâmbio de Informação) — que define qual símbolo cada número representa. Para consulta, veja a tabela ASCII completa.

65→'A'
97→'a'
48→'0'
0→'\0'

Esses tipos, e algumas variações deles, não são capazes de representar um conjunto de bytes como uma palavra, um nome ou uma frase — ou seja, como uma sequência de caracteres. Para isso, precisamos conhecer um novo conceito: a string.

String: toda a informação composta por caracteres alfanuméricos, auxiliares, visíveis e invisíveis, que possam expressar um significado ou não.

Não há o tipo string na linguagem C.

Representação de strings em C

Apesar de não existir um tipo string, podemos simulá-lo combinando dois itens já conhecidos:

  • char, capaz de representar os caracteres da tabela ASCII;
  • vetores, capazes de armazenar uma sequência de caracteres.

Ou seja: para declarar uma "string" em C, declaramos um vetor de char:

char palavrao[10];

Toda string em C tem tamanho fixo quando declarada como vetor — não se esqueça de especificar quantos caracteres o vetor será capaz de armazenar.

O caractere nulo não é visível no terminal de saída e não compõe o tamanho da string ("caramba" tem 7 caracteres). Sua utilidade está em marcar o fim da string para as funções que a manipulam. Sem o \0, o que existe é apenas um vetor de caracteres — não uma string.

Inicialização de strings

A linguagem C permite inicializar uma string já atribuindo um valor no momento da declaração:

char palavrao[10] = "caramba";

O vetor terá espaço para 10 caracteres, mas nem todos estarão ocupados — o \0 é colocado automaticamente logo após o último caractere. Também é possível omitir o tamanho:

char palavrao[] = "caramba";

Nesse caso, o compilador reserva exatamente o espaço necessário: 1 posição para cada letra mais o \0.

Imprimindo e lendo strings

Impressão

Qualquer string pode ser impressa com printf, usando o formatador %s:

printf("O palavrão digitado foi %s.", palavrao);

Leitura

Existem funções específicas para ler strings, mas o scanf — já conhecido de outros tipos — é o mais eficaz. Há dois formatadores para strings:

  • "%s": lê uma única palavra, parando no primeiro espaço em branco.
  • "%[^\n]": lê tudo até a tecla Enter (\n), incluindo espaços — necessário para frases com mais de uma palavra.
char nome[15];
scanf("%s", nome);
char frase[50];
scanf("%[^\n]", frase);

Funções da biblioteca string.h

Para tratar um vetor de caracteres como uma string de fato, além do \0, usamos a biblioteca string.h, que reúne diversas funções de manipulação. As principais:

strlen — comprimento

Retorna o tamanho de uma string passada como argumento (sem contar o \0):

char frase[100] = "O rato roeu";

int l = strlen(frase);
// l terá valor 11

strcpy — cópia

Copia o conteúdo da string do 2º argumento para dentro da string do 1º argumento:

char frase[100] = "O rato roeu";
char frase1[100];

strcpy(frase1, frase);
// frase1 terá o valor "O rato roeu"

Atenção: por que não podemos simplesmente fazer frase1 = frase;, como fazemos com variáveis comuns, para atribuir strings? Pesquise — e depois confira sua resposta no quiz abaixo.

strcat — concatenação

Adiciona, ao final da string do 1º argumento, o conteúdo da string do 2º argumento:

char frase[100] = "O rato roeu";
char frase1[100] = "A roupa do rei de roma";

strcat(frase, frase1);
// frase terá o valor "O rato roeuA roupa do rei de roma"
