Registros (structs) em C
tipos compostos, typedef e ponteiro de struct

Até agora cada variável guardava uma informação simples, ou várias do mesmo tipo. Agora vamos agrupar informações diferentes que descrevem uma única coisa, como uma carta de baralho, um pixel ou um número complexo, em um novo tipo criado por nós: o registro, ou struct. Depois, vamos encurtar os nomes com typedef e acessar structs por ponteiros com o operador ->.

struct carta {…} → typedef … Carta → Carta *cp = &c1 → cp->valor

O que é um registro

Até aqui trabalhamos com os tipos nativos (int, float, char), com vetores, com strings e com ponteiros. Todos representam bem informações simples: um número, uma letra, uma lista de valores do mesmo tipo.

A maior parte das coisas que queremos representar em um programa, porém, é formada por várias informações relacionadas que, juntas, descrevem uma única entidade. Para isso a linguagem C oferece os registros, chamados de structs.

Registro (struct): tipo de dados capaz de representar tipos complexos e compostos, agrupando sob um único nome um conjunto de variáveis, possivelmente de tipos diferentes.

Cada variável que compõe um registro é chamada de atributo (também aparece como campo ou membro).

A problemática: complexos, pixels e cartas

Números complexos (ℂ)

Um número complexo como 3 + 2i não é um número: é composto pela parte real e pela parte imaginária. Sem structs, cada complexo exige duas variáveis soltas:

float z1_real, z1_imag;
float z2_real, z2_imag;

Nada no código diz que z1_real e z1_imag pertencem ao mesmo número. E se quisermos uma função que retorne um complexo? Uma função em C só retorna um valor…

Pixel

Cada ponto de uma imagem colorida é descrito por quatro componentes, Red, Green, Blue e Alpha (transparência), cada um de 0 a 255. Uma imagem pequenina de 64 × 64 tem 4096 pixels; com variáveis independentes seriam 4096 × 4 = 16384 variáveis, ou quatro vetores paralelos que precisariam ser mantidos sincronizados à mão. Inviável.

A ideia central

Uma struct é um molde: descreve quais atributos existem. A partir dele criamos quantas variáveis quisermos, cada uma com seus próprios valores.

Declarando o tipo struct

A sintaxe para definir o tipo é:

struct nome_do_tipo {
    tipo atributo1;
    tipo atributo2;
    ...
};

Para a carta de baralho, exatamente como na lousa:

// tipo carta
struct carta {
    int  valor;
    char naipe[10];
    char cor;
    char nome;
};
  • O ponto e vírgula depois da chave, };, é obrigatório. Esquecê-lo gera erros de compilação confusos nas linhas seguintes.
  • Os atributos podem ser de tipos diferentes, inclusive vetores, como naipe[10].
Declarar o tipo não cria variável

Esse bloco apenas ensina ao compilador como é o novo tipo struct carta; nenhuma memória é reservada. Por isso costumamos escrevê-lo fora do main, logo após os #include, para que todas as funções do programa conheçam o tipo.

Variáveis, vetores de structs e inicialização

Com o tipo definido, criamos variáveis como faríamos com um int, sempre escrevendo o tipo completo, struct carta:

// variáveis carta
struct carta carta1;
struct carta baralho[52];
  • carta1 é uma carta.
  • baralho é um vetor de 52 cartas: cada posição do vetor é uma struct completa.

Inicialização na declaração

Como nos vetores, uma struct pode ser inicializada entre chaves, seguindo a ordem em que os atributos foram declarados:

struct carta carta2 = {7, "copas", 'V', '7'};

Acessando atributos: o operador ponto

Para ler ou escrever um atributo usamos variavel.atributo:

carta1.valor = 14;
strcpy(carta1.naipe, "espadas");
carta1.cor  = 'P';
carta1.nome = 'A';

baralho[0].valor = 7;
  • carta1.naipe é uma string, então vale tudo da Unidade II: não podemos fazer carta1.naipe = "espadas";, é preciso strcpy.
  • Em baralho[0].valor, primeiro o índice seleciona a carta; depois o ponto seleciona o atributo.

Cada atributo se comporta exatamente como uma variável comum do seu tipo, então funciona em printf, scanf e expressões:

printf("Carta: %c de %s (valor %d)\n", carta1.nome, carta1.naipe, carta1.valor);

scanf("%d", &carta1.valor);   // int: precisa do &
scanf("%s", carta1.naipe);    // string: não precisa do &

Atribuição entre structs

Diferente dos vetores, structs podem ser copiadas inteiras com =: todos os atributos, inclusive vetores internos como naipe, são copiados.

struct carta copia;
copia = carta1;   // copia valor, naipe, cor e nome

Mas não é possível comparar structs com ==: a comparação deve ser feita atributo por atributo (e o naipe, com strcmp).

Verboso, não? typedef

Ao referenciar uma struct há a necessidade de especificar o tipo completamente, sempre com a palavra struct na frente:

struct carta    c;
struct pixel    p;
struct complexo z;

Verboso, não? Para isso existe o typedef (type definition, definição de tipo), que cria um apelido para um tipo já existente:

typedef tipagem apelido;

Funciona com qualquer tipo, não apenas structs. O C clássico, por exemplo, não tem um tipo booleano, então podemos criar um nome mais expressivo:

typedef int booleano;

booleano achou = 0;   // para o compilador, continua sendo um int
Convenção desta disciplina

Nome da struct em minúsculas (carta) e apelido do typedef com inicial maiúscula (Carta). Assim fica claro, só de olhar, quando estamos usando o apelido.

Três formas de usar typedef com struct

Opção 1: com a struct já declarada

struct carta {
    int  valor;
    char naipe[10];
    char cor;
    char nome;
};

typedef struct carta Carta;

Opção 2: criando a struct já tipada

Declaração do tipo e apelido no mesmo comando:

typedef struct complexo {
    float real;
    float imag;
} Complexo;

Opção 3: criando uma struct anônima

A struct não tem nome; existe apenas o apelido:

typedef struct {
    int  valor;
    char naipe[10];
    char cor;
    char nome;
} Carta;

Em qualquer das três opções, daí em diante basta escrever:

Carta    c1;
Carta    baralho[52];
Complexo z;
Opção 1

Útil quando a struct já existe no código e só queremos o apelido. Valem struct carta e Carta.

Opção 2

Tudo em um lugar. Valem struct complexo e Complexo.

Opção 3

Mais enxuta. Vale só Carta; struct carta não existe.

Ponteiro de struct: (*cp).valor ≡ cp->valor

Tudo o que vimos na Unidade IV vale também para structs. Um ponteiro de struct guarda o endereço de uma variável struct:

Carta c1;
Carta baralho[52];
Carta *cp;

c1.valor = 14;
strcpy(c1.naipe, "espadas");
c1.cor  = 'P';
c1.nome = 'A';

cp = &c1;          // cp aponta para c1

Para acessar um atributo através do ponteiro há duas escritas equivalentes:

desreferencia, depois acessa 
(*cp).valor = 1;
operador seta 
cp->valor = 1;

As duas linhas fazem exatamente a mesma coisa. Veja o que acontece na memória, passo a passo:

PassoInstruçãoc1.valorcp
1Carta c1; Carta *cp;lixolixo
2c1.valor = 14; (e os demais atributos)14lixo
3cp = &c1;14&c1
4(*cp).valor = 1;1&c1
5cp->valor = 1; (mesmo efeito, escrita abreviada)1&c1
Por que os parênteses?

O operador . tem precedência maior que o *. Sem parênteses, *cp.valor é lido como *(cp.valor), e cp é um ponteiro, não uma struct: erro de compilação. A seta -> existe justamente para evitar essa escrita carregada.

Regra prática: variável struct → . · ponteiro para struct → ->.

Structs e funções

Uma struct passada para uma função é passada por valor: a função recebe uma cópia, como acontece com um int. Para que a função altere a struct original, passamos o seu endereço, a mesma passagem por referência da Unidade III, agora usando a seta:

void imprime_carta(Carta c) {          // por valor: só lê
    printf("%c de %s (%c) - valor %d\n", c.nome, c.naipe, c.cor, c.valor);
}

void zera_valor(Carta *cp) {           // por referência: altera
    cp->valor = 0;
}

int main(void) {
    Carta c1 = {14, "espadas", 'P', 'A'};

    imprime_carta(c1);
    zera_valor(&c1);
    printf("%d\n", c1.valor);    // 0
    return 0;
}

De volta aos números complexos

Lembra da problemática do início? Uma função só retorna um valor, mas esse valor pode ser uma struct, carregando as duas partes de uma vez:

Complexo soma(Complexo a, Complexo b) {
    Complexo r;
    r.real = a.real + b.real;
    r.imag = a.imag + b.imag;
    return r;
}

// uso
Complexo z1 = {3.0, 2.0}, z2 = {1.5, -4.0};
Complexo z  = soma(z1, z2);     // 4.5 - 2.0i
